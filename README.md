# 移動ド音程チェッカー

マイク入力の音高を **移動ド（可動ド）** で表示するブラウザアプリです。依存ライブラリなし、HTML 1枚で動きます。

## できること

- キーを設定すると、その主音が「ド」になります（Key=D なら D→ド、E→レ）
- セントメーターで「ちょっと高い／ちょっと低い」が視認できます
- スケールストリップにキーの構成音を並べ、いま鳴っている音をハイライト
- スケール外の音は「ド♯ ／ ♭2度（スケール外）」のように区別表示

### マイナーキー

| 設定 | 内容 |
|---|---|
| 階名体系 | **ラ基準**（日本の移動ド標準・Am なら A=ラ, C=ド）／**ド基準**（短調主音をドと読む） |
| スケール | **ナチュラル** ／ **ハーモニック** ／ **両方** |

ハーモニックを選ぶと、Ⅴ7（Am なら E7）の第3音である **G♯ が「ソ♯・7度（導音）」としてスケール内**に入ります。度数から素の階名を決めて差分を♯♭にする方式なので、「ラ♭」と誤表記されません。

### その他の設定

基準ピッチ A4（392–470Hz）、階名表記（ドレミ／do re mi）、マイク感度、表示の安定化。設定はブラウザに保存されます。

## 使い方

`https://` で開いて「マイク開始」を押すだけです。

> **注意**: ブラウザの仕様上、マイクは `https://` または `http://localhost` でしか使えません。ファイルをローカルに保存して直接開く（`file://`）とマイクは動作しません。

## 技術メモ

- ピッチ検出: NSDF（McLeod Pitch Method）＋放物線補間
- 窓 2048 サンプル（約43ms）、検出域 55–1600Hz、clarity 0.5 未満は棄却
- 検出周期 25ms、直近3回の中央値で平滑化
- 合成波による実測精度: 82.4Hz〜1174.7Hz で **±0.3 cent 以内**
